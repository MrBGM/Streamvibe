📌 Information importante

Pour que l'upload de vidéos fonctionne, le backend doit être configuré avec un endpoint d'upload. Si l'endpoint n'existe pas encore, vous pouvez:

  1. Copier manuellement les fichiers vidéo dans le dossier /videos du serveur
  2. Mettre à jour le champ "URL Vidéo" dans la gestion des contenus avec le chemin: /videos/nom-fichier.mp4
